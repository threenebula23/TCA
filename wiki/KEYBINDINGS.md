# Все клавиши — Lorne v1.0

Полный справочник всех сочетаний клавиш. Также доступен внутри TUI через `F1` или `?` в WIDGET-режиме.

Смотри также: [wiki/VI_EDITOR.md](VI_EDITOR.md) для подробного описания режимов.

---

## NORMAL mode

| Клавиша | Действие |
|---------|----------|
| `h / ←` | Курсор влево |
| `l / →` | Курсор вправо |
| `j / ↓` | Курсор вниз |
| `k / ↑` | Курсор вверх |
| `w / W` | Вперёд на слово |
| `b / B` | Назад на слово |
| `e / E` | Конец слова |
| `0` | Начало строки |
| `^` | Первый непробел строки |
| `$` | Конец строки |
| `gg` | Начало файла |
| `G` | Конец файла |
| `{n}G` | Перейти на строку n |
| `Ctrl+f / Ctrl+b` | Страница вниз / вверх |
| `Ctrl+d / Ctrl+u` | Пол-страницы вниз / вверх |
| `%` | Парная скобка |
| `f/F/t/T{c}` | Поиск символа в строке |
| `; / ,` | Повторить f/t |
| `* / #` | Поиск слова под курсором |
| `i / I` | INSERT в курсоре / начале строки |
| `a / A` | INSERT после курсора / конце строки |
| `o / O` | Новая строка ниже / выше |
| `x / X` | Удалить символ |
| `r{c}` | Заменить символ |
| `d{motion} / dd / D` | Удалить |
| `c{motion} / cc / C` | Изменить |
| `y{motion} / yy` | Скопировать |
| `p / P` | Вставить после / перед |
| `u / Ctrl+r` | Отменить / повторить |
| `.` | Повторить изменение |
| `~` | Переключить регистр |
| `>> / <<` | Отступ |
| `J` | Объединить строки |
| `v / V` | → VISUAL |
| `:` | → COMMAND |
| `Space+w` | → WIDGET |
| `{n}{оп}` | Счётчик повторений |

---

## INSERT mode

| Клавиша | Действие |
|---------|----------|
| `Esc / Ctrl+[` | → NORMAL |
| `Ctrl+w` | Удалить слово перед курсором |
| `Ctrl+u` | Удалить до начала строки |
| `Backspace` | Удалить символ |
| `Enter` | Новая строка |
| Любой символ | Вставить символ |

---

## VISUAL mode

| Клавиша | Действие |
|---------|----------|
| Движения NORMAL | Расширить выделение |
| `o` | Другой конец выделения |
| `y` | Скопировать |
| `d / x` | Вырезать |
| `c` | Изменить |
| `> / <` | Отступ |
| `~ / u / U` | Регистр |
| `Esc` | → NORMAL |

---

## COMMAND mode

| Команда | Действие |
|---------|----------|
| `:w` | Сохранить |
| `:q / :q!` | Закрыть / принудительно |
| `:wq / :x` | Сохранить и закрыть |
| `:e {путь}` | Открыть файл |
| `:bn / :bp` | Следующая / предыдущая вкладка |
| `:{n}` | Перейти на строку |
| `:%s/{найти}/{замена}/g` | Замена |
| `/{шаблон}` | Поиск вперёд |
| `?{шаблон}` | Поиск назад |
| `:!{команда}` | Команда оболочки |
| `Esc` | → NORMAL |

---

## WIDGET mode

| Клавиша | Действие |
|---------|----------|
| `Space+c` | Фокус в чат |
| `Space+e` | Фокус в проводник |
| `Space+a` | Активные агенты |
| `Space+s` | Настройки |
| `Space+t` | Новый терминал |
| `1–6` | Вкладка по номеру |
| `[ / ]` | Предыдущая / следующая вкладка |
| `Tab / Shift+Tab` | Цикл по виджетам |
| `j / k` | Прокрутка |
| `m / M` | Режим / модель |
| `s` | Остановить агента |
| `+ / - / =` | Ширина боковой панели |
| `?` или `F1` | Справка по клавишам |
| `Esc` | → NORMAL |

---

## Глобальные

| Клавиша | Действие |
|---------|----------|
| `F1 / ?` | Открыть справку по клавишам |
| `Ctrl+Q` | Выход |
| `Ctrl+B` | Показать/скрыть боковую панель |
| `Ctrl+S` | Сохранить файл |
| `F5` | Запустить текущий файл |
| `Esc` | Фокус в чат |

---

## Чат

| Клавиша | Действие |
|---------|----------|
| `Enter` | Отправить сообщение |
| `@` | Автодополнение файла |
| `/help` | Команды чата |
