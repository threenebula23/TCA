# Редактор в стиле Vi — Lorne v1.0

Lorne использует полноценный Vi-подобный редактор (`ViTextArea`) во всех вкладках с кодом.
Поддерживаются 5 режимов работы. Без мыши можно сделать всё.

---

## Переключение режимов

```
NORMAL ──i/a/o──▶ INSERT ──Esc──▶ NORMAL
NORMAL ──v/V────▶ VISUAL ──Esc──▶ NORMAL
NORMAL ──:──────▶ COMMAND ──Enter/Esc──▶ NORMAL
NORMAL ──Space+w▶ WIDGET ──Esc──▶ NORMAL
```

| Из / В    | NORMAL | INSERT | VISUAL | COMMAND | WIDGET |
|-----------|--------|--------|--------|---------|--------|
| NORMAL    | —      | i/a/o/s/R/I/A/O | v/V | : | Space+w |
| INSERT    | Esc / Ctrl+[ | — | — | — | — |
| VISUAL    | Esc | — | — | — | — |
| COMMAND   | Enter / Esc | — | — | — | — |
| WIDGET    | Esc | — | — | — | — |

---

## Режим NORMAL

**Навигация курсора**

| Клавиша | Действие |
|---------|----------|
| `h / ←` | Курсор влево |
| `l / →` | Курсор вправо |
| `j / ↓` | Курсор вниз |
| `k / ↑` | Курсор вверх |
| `w / W` | Вперёд на слово |
| `b / B` | Назад на слово |
| `e / E` | Конец слова |
| `0` | Начало строки (колонка 0) |
| `^` | Первый непробел строки |
| `$` | Конец строки |
| `gg` | Начало файла |
| `G` | Конец файла |
| `{n}G` | Перейти на строку n |
| `Ctrl+f` | Страница вниз |
| `Ctrl+b` | Страница вверх |
| `Ctrl+d` | Пол-страницы вниз |
| `Ctrl+u` | Пол-страницы вверх |
| `%` | Перейти к парной скобке |
| `f{c}` | Найти символ c вправо по строке |
| `F{c}` | Найти символ c влево |
| `t{c}` | До символа c (перед ним) |
| `T{c}` | До символа c (назад) |
| `;` | Повторить f/t вперёд |
| `,` | Повторить f/t назад |
| `*` | Искать слово под курсором вперёд |
| `#` | Искать слово под курсором назад |

**Редактирование**

| Клавиша | Действие |
|---------|----------|
| `i / I` | Вставка в курсоре / начале строки |
| `a / A` | Вставка после курсора / конце строки |
| `o / O` | Новая строка ниже / выше |
| `x / X` | Удалить символ под / перед курсором |
| `r{c}` | Заменить символ под курсором |
| `R` | Режим замены |
| `s / S` | Удалить символ и войти / заменить строку |
| `d{motion}` | Удалить по движению |
| `dd` | Удалить строку |
| `D` | Удалить до конца строки |
| `c{motion}` | Изменить по движению |
| `cc / C` | Изменить всю строку / до конца |
| `y{motion}` | Скопировать по движению |
| `yy / Y` | Скопировать строку |
| `p / P` | Вставить после / перед курсором |
| `u` | Отменить |
| `Ctrl+r` | Повторить |
| `.` | Повторить последнее изменение |
| `~` | Переключить регистр символа |
| `>> / <<` | Отступ вправо / влево |
| `J` | Объединить строку ниже с текущей |
| `{n}{оп}` | Счётчик повторений (3dd, 5j …) |

## Режим INSERT

| Клавиша | Действие |
|---------|----------|
| `Esc / Ctrl+[` | → NORMAL |
| `Ctrl+w` | Удалить слово перед курсором |
| `Ctrl+u` | Удалить до начала строки |
| `Ctrl+h / Backspace` | Удалить символ перед курсором |
| `Ctrl+j / Enter` | Новая строка |
| `Ctrl+t / Ctrl+d` | Отступ / убрать отступ |
| Любой символ | Вставить символ |

---

## Режим VISUAL (v / V / Ctrl+v)

| Клавиша | Действие |
|---------|----------|
| Все движения NORMAL | Расширить выделение |
| `o` | Перейти к другому концу выделения |
| `y` | Скопировать выделение → NORMAL |
| `d / x` | Вырезать выделение → NORMAL |
| `c` | Изменить выделение → INSERT |
| `>` | Увеличить отступ |
| `<` | Уменьшить отступ |
| `~` | Переключить регистр |
| `u / U` | Строчные / Заглавные |
| `J` | Объединить строки |
| `Esc` | → NORMAL |

---

## Режим COMMAND (:)

| Команда | Действие |
|---------|----------|
| `:w` | Сохранить файл |
| `:w {имя}` | Сохранить как |
| `:q` | Закрыть вкладку |
| `:q!` | Закрыть без сохранения |
| `:wq` / `:x` / `ZZ` | Сохранить и закрыть |
| `:e {путь}` | Открыть файл |
| `:bn` / `:bp` | Следующая / предыдущая вкладка |
| `:{n}` | Перейти на строку n |
| `:%s/{найти}/{замена}/g` | Глобальная замена |
| `/{шаблон}` | Поиск вперёд (n/N для навигации) |
| `?{шаблон}` | Поиск назад |
| `:!{команда}` | Выполнить команду оболочки |
| `Esc` | Отменить → NORMAL |

## Режим WIDGET (Space+w — управление UI без мыши)

**Фокус панелей**

| Клавиша | Действие |
|---------|----------|
| `Space+c` | Фокус в чат |
| `Space+e` | Фокус в проводник файлов |
| `Space+a` | Фокус на активные агенты |
| `Space+s` | Открыть настройки |
| `Space+t` | Новая вкладка терминала |
| `Space+w` | Войти в WIDGET из NORMAL |
| `1–6` | Перейти к вкладке по номеру |
| `[ / ]` или `h / l` | Предыдущая / следующая вкладка |
| `Tab / Shift+Tab` | Цикл по виджетам |
| `Esc` | → NORMAL |
| `?` или `F1` | Открыть справку по клавишам |

**В проводнике файлов**

| Клавиша | Действие |
|---------|----------|
| `j / k` | Выбор вниз / вверх |
| `Enter` | Открыть выбранный файл |
| `h / l` | Свернуть / развернуть папку |
| `n / N` | Новый файл / папка |
| `d` | Удалить (с подтверждением) |
| `r` | Переименовать |
| `a` | Добавить в контекст агента |
| `/` | Поиск в дереве |

**В панели чата**

| Клавиша | Действие |
|---------|----------|
| `j / k` | Прокрутка чата вниз / вверх |
| `Ctrl+d / Ctrl+u` | Прокрутка пол-страницы |
| `gg / G` | В начало / конец чата |
| `i` | Войти в INSERT (ввод в чат) |
| `m` | Сменить режим агента |
| `M` | Следующая модель |
| `s` | Остановить агента |
| `z / Z` | Развернуть / восстановить чат |

**Изменение размеров**

| Клавиша | Действие |
|---------|----------|
| `+` | Расширить боковую панель (+2 cols) |
| `-` | Сузить боковую панель (−2 cols) |
| `=` | Сброс ширины боковой панели |

## Строка состояния

Строка состояния отображается в правом нижнем углу и показывает текущий режим и 4–5 частых клавиш:

```
[NORMAL]   h/j/k/l · i:вставка · v:выделение · ::команда · Space+w:widget  F1:справка
[INSERT]   -- ВСТАВКА -- · Esc:normal
[VISUAL]   движение · y:копировать · d:вырезать · >/<:отступ · Esc:normal
[COMMAND]  :команда · Enter:выполнить · Esc:отмена
[WIDGET]   Space+c:чат · Space+e:файлы · [/]:вкладки · j/k:прокрутка · Esc:normal
```

Цвета: NORMAL=фиолетовый, INSERT=зелёный, VISUAL=синий, COMMAND=жёлтый, WIDGET=голубой.

---

## Подсказки

- `F1` или `?` в WIDGET → открыть панель клавиш в новой вкладке
- Строка состояния всегда показывает текущий режим и 4–5 частых клавиш
- Все стандартные vi-операции поддерживают счётчик: `3dd`, `5j`, `2yy`
