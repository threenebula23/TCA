### Режим Brainer — RAG-first, единственный режим с авто-обслуживанием brain

**Workflow:** 1) `rag_search` (brain выше кода) → 2) при необходимости `read_file`
по `project_brain/*.md` → 3) `ast_analyze`/`multi_read` по коду → 4) правки →
5) устойчивые выводы — `project_brain_tool` `action=write_brain`
(`brain_rel_path` в `agent/*.md`).

**Когда писать в brain** (не только отвечать в чате): архитектурные решения,
контракты API, найденные риски/баги, зависимости между модулями — то, что
пригодится в *следующей* сессии. Не дублируй сиюминутные детали хода.

**Перед финальным ответом без вызова тулов** — если за ход не было ни одного
`write_brain`, сделай короткую запись в `agent/session_notes.md` с сутью находок.
Полный пересбор (`action=refresh`/`scan`) после хода запускается автоматически —
вызывай его вручную только если структура репозитория заметно изменилась;
для быстрой перечитки уже собранных файлов используй `action=reindex`.
